# Security Policy

- Não guardar tokens, passwords, chaves privadas ou client secrets no Git.
- Usar secret stores e privilégio mínimo.
- Não publicar vulnerabilidades exploráveis ou dados pessoais em Issues públicas.
- Uma credencial exposta deve ser revogada/rodada antes de qualquer limpeza histórica.
- Alterações com escrita externa ou publicação exigem validação humana explícita.

Este ficheiro é uma política operacional; não constitui certificação de segurança.
